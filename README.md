## Proyectos destacados

### [ONT-Info](https://github.com/MauroGuar/ONT-Info)

Proyecto de pasantía, desarrollado en un equipo de tres personas durante las prácticas profesionalizantes de la secundaria técnica. Aplicación web que automatiza la consulta del estado de una ONT (terminal de red óptica) de un cliente:

- **Consulta por SSH** a la OLT (Huawei SmartAX MA5800) para obtener los datos de la ONT.
- **Caché de consultas** en MongoDB para reutilizar resultados recientes.
- **Despliegue con Docker Compose** (servicios de Flask y MongoDB).

`Python` · `Flask` · `MongoDB` · `Docker` · `JavaScript`

### [Spotify-Clone (OurMusic)](https://github.com/Santiagocapi/Spotify-Clone)

Reproductor de música personal inspirado en Spotify, construido con el stack MERN:

- **Frontend** en React con Vite e interfaz responsive.
- **API REST** en Node.js y Express, con base de datos en MongoDB.
- **Autenticación** de usuarios y subida de archivos de audio.

`React` · `Vite` · `Node.js` · `Express` · `MongoDB`

### [fifa-career-manager](https://github.com/Santiagocapi/fifa-career-manager)

Aplicación web full-stack para llevar el registro de partidas del Modo Carrera de EA FC:

- **Gestión de carreras y plantel**: múltiples partidas guardadas, estadísticas por partido e historial de temporadas.
- **Pizarra táctica** con drag and drop y cálculo de valoraciones del equipo en tiempo real.
- **Datos por usuario** protegidos con Row Level Security en Supabase.

`React` · `TypeScript` · `Vite` · `Tailwind CSS` · `Supabase`

### [tp-final-python](https://github.com/Santiagocapi/tp-final-python)

Trabajo práctico final de Programación con Python, dividido en tres ejercicios:

- **Análisis de sensores**: sanitización de datos y estadísticas.
- **Gestor de inventario**: modelo de productos con excepciones propias y persistencia en JSON.
- **Panel de sustentabilidad**: aplicación Django con vistas, plantillas y tests unitarios.

`Python` · `Django` · `unittest`
